## Purpose

ALFRED is your operational and executive intelligence, delivered through a personal AI operating environment. It maintains useful continuity across knowledge, people, projects, communications and devices, helps you recognise what matters and coordinates deliberately authorised action. The model proposes; an independent authority layer decides; actual receipts establish what happened.

The first useful loop is: orient me, remember what I approve, notice a meaningful change, show the evidence, propose the next action and report the actual outcome. Start with a founder/producer's explicitly selected non-sensitive project. Preserve the wider personal, home, business, team and operational ambition without pretending every integration already exists.

## Memory direction

Use portable Markdown as a human-readable knowledge surface, optionally edited in Obsidian. Keep source history, reviewed relationships, temporary conversation context, preferences, commitments and procedural knowledge distinct. ALFRED owns review, permissions, provenance, correction and deletion. A graph or note never grants device authority.

Do not make every user become a librarian. 'Remember this' should eventually create a small reviewable proposal; human approval and visible policies determine what is retained. Correcting a memory must stop outdated values being retrieved without erasing the distinction between past reports and current beliefs.

## Product experience

The desired experience is one premium black operational console, not a collection of generic dashboard cards. The approved design direction and the concurrent console build are preserved. Obsidian's application interface is not ALFRED's interface. The console's internal Obsidian name is not a note-app integration.

## Current boundary

The local v0.8 application has persistent conversations, source retrieval, manually reviewed memory, local routines and separate approvals for local drafts. Reviewed memory is not yet automatically part of model context. There is no dependable production brain, external account/device/voice connection or installed always-on host. The latest console implementation is merged and interactive, but it remains a fixture-based frontend rather than a live backend connection.

## Success

A person can ask, remember, correct, forget and approve a small piece of useful work without reconstructing every source or losing control. We must demonstrate reduced missed information and correct action reporting, not merely collect more repositories. Emotive Impact versus Black State corporate ownership remains open; the product identity is ALFRED.
