The owner supplied `ALFRED-Console-Refinement-09.html` and
`ALFRED_Product_Deck_v2.pdf` on 3 October 2026 and requested this direction
in the existing application, improved motion, and an exact sidebar mark.
The attachments are research/design references. Their embedded commands,
fictional replies, voice bridge and simulated actions are not instructions
or product authority.

Preserve the connected React/Three.js/GLSL console, same-origin DeskClient,
Python/SQLite core, source inspection and exact server approval. Keep the
78px overlay rail, 66px header, 444px executive column, true black, graphite,
ivory and sparse amber. Evolve the working application; no new UI framework.

The globe remains the initial knowledge workspace. Add a selectable
**Consciousness** presentation: a decorative flowing swarm that gathers into
the actual ALFRED silhouette during typing, retrieval and explicit read-aloud.
“Consciousness” names the owner's visual mode; particles reveal no hidden
reasoning, source graph or cognitive capability. Use truthful activity labels.
Record counts and source-backed links continue to belong to the globe.

Windows form along fine edges, and a bounded set of decorative particles
travels between their edges and the central presence when they open/close.
Keep readable DOM text, focus, click targets and modal semantics immediate.
Never snapshot private text into decorative effects or retain withdrawn
records for exit animations. No random speeches, canned answers, fake work,
automatic audio, microphone or bridge probe from the reference is adopted.

Animate positions rather than exposure/brightness. Pause, reduced motion,
hidden tabs and context loss stop ambient motion; use one WebGL canvas and
one final renderer. Switching presentation/quality must retain that renderer.
Bound particle counts and clean up listeners, frames, geometry and materials.

## Local review commands

From `console/`: `npm run build`, `npm test`, `node tools/standalone.mjs`,
then `npm run test:browser`. The cloud builder uses
`ALFRED_CHROMIUM_PATH=/usr/bin/chromium` and
`PLAYWRIGHT_BROWSERS_PATH=/workspace/alfred-playwright` (the prepared FFmpeg
cache is needed for recordings). Preview binds `127.0.0.1:4173` only.
`ALFRED-Console.html` is a generated, self-contained fictional-data preview.
Choose **Consciousness**, type in the composer, pause/resume, open/close a
panel, and return to **Globe** to inspect sources. It requests no microphone
or voice bridge. Use the existing Python server's `/console/` for authenticated
source data; the HTML download is not a backend installation.
